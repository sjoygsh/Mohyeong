Getting Started

Mohyeong is an enhanced fork of Mihon for Android. It includes all of Mihon's features plus exclusive additions like linked sources, expanded sync backends, and per-row conflict resolution.

Android 8.0 or higher required. Mohyeong targets the same minimum SDK as Mihon (API 26).

Installation

  1. Download the APK Go to the Releases page on GitHub and download the latest .apk file.
  2. Allow unknown sources On your Android device, go to Settings → Apps → Special app access → Install unknown apps and allow your browser or file manager.
  3. Install Open the downloaded APK and tap Install. Mohyeong uses the package ID app.mohyeong — it will not conflict with Mihon if both are installed.
  4. Restore a backup (optional) If you're coming from Mihon, use More → Backup and restore to import your existing .tachibk backup file.

Migrating from Mihon

Mohyeong reads standard Mihon .tachibk backup files without modification. To migrate:

  • In Mihon: More → Settings → Data and storage → Create backup
  • Transfer the .tachibk file to your device
  • In Mohyeong: More → Backup and restore → Restore backup
Your reading history, categories, tracking links, and chapter progress are all preserved in the backup.

Adding Sources

Mohyeong uses the same extension system as Mihon. Go to Browse → Extensions, enable the extensions you want, and they'll appear as sources in Browse.

Linked Sources Mohyeong exclusive

Linked Sources lets you attach multiple source entries to a single manga in your library. The entry you originally added is the primary; everything else you attach is a linked source. When you open the primary, chapters from every linked source are merged into one chapter list — and library updates walk every linked source so their new chapters appear under the primary entry, even when the primary itself hasn't updated.

Why use linked sources?

Some titles exist on multiple sources with different translation groups, quality levels, or update speeds. Instead of maintaining separate library entries, link them so the fastest or highest-quality chapter always surfaces under one entry.

How to link sources

  1. Open the primary manga Open the entry you want to keep in your library as the primary.
  2. Open the overflow menu Tap the ⋮ (three-dot menu) in the top-right corner of the manga detail screen.
  3. Tap "Linked Sources" The dialog lists favorited entries you can link.
  4. Select and confirm Choose the source entries to link. The merged chapter list updates immediately.

How merged chapters behave

  • Library updates walk every linked source. If Asura's mirror of a title gets a new chapter, it appears under your primary library entry — even if the primary source itself never updated. A broken primary source no longer hides updates from working mirrors; a broken mirror no longer aborts updates from siblings.
  • Dedupe is by recognized chapter number. The primary always wins ties; if the primary is missing a chapter number, the earliest-linked source fills the gap.
  • Read state is mirrored across linked sources by chapter number. Marking Ch.10 read on the merged list marks Ch.10 read on every linked source's row, so swapping the primary later doesn't reset your progress.
  • Downloads go to each chapter's true source folder. A chapter served by Asura is downloaded against Asura's source with Asura's URL — not silently dumped into the primary's folder.
  • Pull-to-refresh on the manga screen always walks every linked source, not just on primary failure.

Limitations

  • Metadata stays primary-only. Cover, title, and description always come from the primary entry. Linked-source metadata is ignored.
  • No in-app way to swap primary ↔ linked. If you want to flip which entry is primary, unlink and relink in the opposite direction.
  • Removing the primary from library only prompts about primary's downloads. Linked-source chapters of the same series stay downloaded — clean them up from each linked entry separately.
  • Linked entries don't need to stay in your library. Links live independently of the favorite flag, so you can unfavorite a linked entry and the link still works. Uninstalling the source extension, however, silently skips that source on every refresh.
Note: Linked source relationships are stored locally. They are not part of any global database.

Cloud Sync Mohyeong exclusive

Mohyeong supports four sync backends. All use the same bidirectional merge engine: pull remote → apply locally (timestamp merge) → snapshot merged state → push back. Your data is never silently overwritten.

Backend Auth Self-hosted Best for
SyncYomiAPI keyYesFull control, server-side merge
WebDAVUsername + passwordYesNextcloud, Synology, own server
Google DriveOAuth access tokenNoEasiest cloud setup
DropboxPersonal access tokenNoDropbox users

To enable sync: More → Settings → Sync → choose a service and enter credentials.

SyncYomi

SyncYomi is a self-hosted sync server. The server performs the final merge and returns a merged payload, so conflict resolution happens server-side.

  • Host: Full URL of your SyncYomi instance (e.g. https://sync.example.com)
  • API Key: The key configured on your server

WebDAV

WebDAV stores a single mihon-sync.tachibk file at the root of your WebDAV URL. Client-side merge happens via BackupRestorer's per-row timestamp logic.

  • URL: WebDAV server root (e.g. https://cloud.example.com/remote.php/dav/files/user/)
  • Username: Your WebDAV username
  • Password: Your WebDAV password
Tested with Nextcloud and Synology DSM. Any server that supports HTTP GET/PUT on a path should work.

Google Drive

Google Drive stores one file named mihon-sync.tachibk in the app's Drive space (drive.file scope — only files Mohyeong created are accessible).

  1. Get an access token Use the Google OAuth Playground. Select scope https://www.googleapis.com/auth/drive.file, authorize, and copy the access token.
  2. Enter it in Mohyeong More → Settings → Sync → Select Google Drive → paste into Access Token.
Access tokens expire (usually 1 hour). You'll need to refresh the token periodically. Mohyeong does not handle OAuth refresh automatically.

Dropbox

Dropbox stores /mihon-sync.tachibk in your Dropbox root using a long-lived personal access token.

  1. Create a Dropbox app Go to dropbox.com/developers/apps, create an app with Full Dropbox access.
  2. Generate an access token In the app settings, click Generate under "Generated access token".
  3. Enter in Mohyeong More → Settings → Sync → Select Dropbox → paste the token.

Conflict Resolution Mohyeong exclusive

Standard Mihon sync uses last-write-wins at the whole-backup level — whichever device synced most recently overwrites everything. Mohyeong resolves conflicts at the row level using lastModifiedAt timestamps.

  • Manga metadata — the version with the higher lastModifiedAt timestamp wins. If timestamps are equal, version counter acts as tiebreaker.
  • Chapter read state — lastModifiedAt comparison. If the DB entry is newer, its read/bookmark/lastPage values are kept. Bookmarks are always sticky (never unset by a sync).
  • Categories, tracking, history — merged additively; entries are never deleted by a sync unless the backup explicitly omits them.

Library

Your library is the central hub for all manga you're following. Add titles from any source by tapping the bookmark icon on a manga's detail page.

  • Categories — organise manga into custom categories (see Categories)
  • Filters — filter by read status, source, category, or custom tags
  • Sort — by last read, alphabetical, total chapters, or unread count
  • Bulk actions — mark as read, move category, download, delete in bulk

Tracking

Mohyeong supports all the same tracking services as Mihon. Connect your accounts in More → Settings → Tracking.

  • MyAnimeList
  • AniList
  • Kitsu
  • MangaUpdates
  • Shikimori
  • Bangumi

Reading progress is synced automatically after you finish a chapter.

Reader

Multiple reading modes are available per-manga or as a global default:

  • Right to Left / Left to Right — paged horizontal reading
  • Vertical — continuous vertical scroll
  • Webtoon — optimised for long-strip webtoons, no gaps
  • Continuous horizontal — horizontal strip reading

Additional reader options: brightness control, color filter, page scale, crop borders.

Downloads

Download chapters for offline reading. Downloads are stored in your configured storage location (More → Settings → Data and storage).

  • Download individual chapters or bulk-download from the chapter list
  • Auto-download new chapters on library update
  • Download queue with pause/resume

Local Source

The Local source lets you read manga stored on your device — no extension required. Put your files in the configured storage folder (More → Settings → Data and storage → Storage location), under the local subdirectory. The app scans it the next time you open the Local source.

Folder layout

<Storage>/Mohyeong/local/
    My Series Title/
        cover.jpg            (optional cover image)
        details.json         (optional metadata)
        Chapter 1/           (folder of images = one chapter)
            001.jpg
            002.jpg
        Chapter 2.cbz        (archive = one chapter)
        Chapter 3.epub       (EPUB = one chapter)

Each top-level folder under local/ is one series. Chapters can be either subfolders of images or archive files (.zip, .cbz, .rar, .cbr, .epub).

Metadata (optional details.json)

Drop a details.json next to the chapters to override the title, author, status, description, and genre:

{
  "title": "My Series Title",
  "author": "Author Name",
  "artist": "Artist Name",
  "description": "Short synopsis",
  "genre": ["Action", "Adventure"],
  "status": "1",
  "_status values": ["0 = Unknown", "1 = Ongoing", "2 = Completed", "3 = Licensed", "4 = Publishing finished", "5 = Cancelled", "6 = On hiatus"]
}

Cover image

Add a cover.jpg (or .png) inside the series folder to set a custom cover. Otherwise the first page of the first chapter is used.

Categories

Categories help you organise your library. Create them in More → Settings → Library → Edit categories. Manga can belong to multiple categories.

FAQ — Differences from Mihon

Is Mohyeong compatible with Mihon backups?

Yes. Mohyeong reads and writes standard .tachibk backup files. You can restore a Mihon backup in Mohyeong and vice versa.

Can I install both Mihon and Mohyeong?

Yes. Mohyeong uses the package ID app.mohyeong, which is different from Mihon's app.mihon. They won't conflict.

Does Mohyeong receive Mihon upstream updates?

Mohyeong is based on a specific Mihon version and is updated manually. Check the releases page for the current base version.

Is this endorsed by the Mihon team?

No. Mohyeong is an independent fork. It is not affiliated with or endorsed by the Mihon project. Mihon is open-source under Apache 2.0, which permits forks.

FAQ — Sync Troubleshooting

Sync says "auth failed" for Google Drive

Your access token has expired. OAuth Playground tokens are typically valid for 1 hour. Generate a new one and update it in sync settings.

WebDAV sync fails with 405 or 401

Check that your WebDAV URL is the correct base path, that your username/password are right, and that the server allows PUT requests on that path.

Dropbox returns "path/not_found" on first sync

This is expected on the first sync — no file exists yet. Mohyeong will create it. If it persists after the first sync, check that your access token has Full Dropbox access scope.

FAQ — Linked Sources

Can I link more than two sources?

Yes, you can link any number of sources to a single manga entry.

Will linked sources affect my reading history?

History is recorded per chapter. Chapters read from a linked source show in your history under that source's identity, but all appear in the single manga entry's chapter list.

Are linked source relationships backed up?

Yes, they are included in sync and backup exports.
