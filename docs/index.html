Mohyeong — Enhanced Manga Reader

A powerful open-source manga reader for Android. Everything Mihon does, plus linked sources, multi-backend cloud sync, and smarter conflict resolution.

What's included

Connect multiple sources to a single manga entry. Chapters from all linked sources appear in one unified list — no duplicates, no juggling.

Cloud Sync

Your library, everywhere

Mohyeong supports four sync backends. All use the same bidirectional merge engine with timestamp-based conflict resolution.

🔄

SyncYomi

Self-hosted server sync. Snapshot local → POST to server → server merges → apply merged result.

📁

WebDAV

Works with Nextcloud, Synology, or any WebDAV server you already run. HTTP Basic auth.

🟡

Google Drive

Uses your personal Google Drive via OAuth access token (drive.file scope). One file, streamed upload.

📦

Dropbox

Long-lived personal access token. Stores a single .tachibk file, overwritten on each sync.

Built on the shoulders of giants — with AI help

Mohyeong is a fork of Mihon, which is itself a continuation of Tachiyomi. Both are open-source under the Apache 2.0 license.

The additional features in Mohyeong — linked sources, expanded sync transports, conflict resolution, reactive sync status — were designed and implemented with the direct assistance of Claude (Anthropic). No attempt is made to obscure this; AI collaboration was an intentional and integral part of the development process.
