Mohyeong

A manga reader for Android, built around the question a reader actually has: what is next, and where was I.

Download APK Read the docs
What it is

Ordered by where you left off

Most library apps answer "what do I own". Following ongoing series only ever raises one question, so the home screen is built around that instead of around a grid of everything.

📖

Continue

What you are part way into, with the chapter and the position you stopped at, in front of everything else.

🌙

Tonight

Every chapter that has arrived, newest first. It is the updates surface, not a summary of one: refresh, filters, search and bulk actions all live here. There is no separate Updates tab.

🗓️

Upcoming

A calendar of predicted releases, measured from how often each series has actually been updating.

🧩

Script extensions

Sources are JavaScript the app runs itself, not APKs installed through Android. Adding one is a file, not an install prompt.

Different from Mihon
🎴

Sources you recognise

Every browse row wears that website's own logo, fetched once from the site and cached. A list of thirty identical glyphs is a list you have to read line by line.

📕

Five reading modes

Paged left to right, right to left or vertical, plus long strip with or without gaps, set globally or per series, with crop borders, colour filter and an e ink flash mode.

Your data

Yours, and portable

One folder holds everything. Backups are a file you keep, sync is a conversation between installs, and the two are not the same thing.

☁️

Four sync backends

SyncYomi, WebDAV, Google Drive or Dropbox. Choose what takes part: library, categories, chapters, history, tracking.

⚖️

Per row merging

The most recently changed version of each entry wins, rather than the whole of whichever device synced last. Deleting is recorded as an act with its own time, so it does not come back.

💾

Backups that restore

Library, categories, history, chapter states, tracking links and source settings in one file. Restoring merges rather than replaces.

🔗

Tracking

AniList, MyAnimeList, Kitsu, MangaUpdates, Shikimori, Komga and Suwayomi. Linked per series, so nothing leaves the device until you link one.

📁

Local source

Point it at a folder of CBZ or ZIP archives, or loose images, and read what is already on the device.

🔒

Locked and incognito

Require the device lock to open, hide contents in the app switcher, and an incognito mode that says so while it is on.

Honest about it

What it does not do

Worth knowing before you install rather than after.

🚫

Mihon extensions do not work

Theirs are Android APKs; these are scripts. A Mihon backup restores your library and history, but you will need the matching Mohyeong extension for each source before those entries load.

🌑

Dark only

No light theme and no follow the system. The interface is designed against a black ground, and rather than ship switches that move nothing, they are not there.

🤝

Not affiliated with Mihon

An independent project that follows Mihon's behaviour closely. Please do not take problems here to them.
